# مسبحة إلكترونية — Android APK

هذا المشروع يغلّف ملف HTML الأصلي داخل تطبيق Android باستخدام WebView.

## بناء APK من GitHub
1. ارفع المجلد إلى مستودع GitHub جديد.
2. افتح تبويب Actions.
3. اختر Build APK ثم Run workflow.
4. بعد انتهاء البناء، افتح نتيجة التشغيل ونزّل artifact باسم Mesbaha-Electronic-Debug-APK.
